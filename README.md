# NO-OnlyAirTargets4A2A
A simple Nuclear Option mod that limits HMD targeting to air targets when you have a Fox-2 or Fox-3 selected. Niece use case, 100% AI coded using Grok.

This mod checks the seeker type of your selected weapon whenever you press the lock button. When it detects an IR or ARH air-to-air missile, it blocks all ground targets from being locked by the HMD. This makes targeting more efficient in case of clusters of symbols without needing to mess with the target filters mid-flight.
Toggleable via config manager/F1 menu

Upcoming features and changes:

- possiblillity to switch from hard-blocking all ground targets to an "Air-biased" mode where you can still lock everything with stronger air bias when A2A weapons are selected
- ability to block flying missiles from being locked when having AGMs or AGRs selected
- added compatibility with the AAM-21 GLAIVE SARH mod missile
