# NO-OnlyAirTargets4A2A (SmartTargeting)
A simple Nuclear Option mod that limits HMD targeting to air targets when you have a Fox-2 or Fox-3 selected. Niece use case, 100% AI coded using Grok.

This mod checks the seeker type of your selected weapon whenever you press the lock button. When it detects an IR or ARH air-to-air missile, it blocks all ground targets from being locked by the HMD. This makes targeting more efficient in case of clusters of symbols without needing to mess with the target filters mid-flight. Also blocks flying missiles from being locked when the selected weapon is laser or optically guided.
Toggleable via config manager/F1 menu. Works with all missiles from Aryx´ mods. Does now also work with the AAM-21 Glaive. Other weaponpacks untested.
